# Contributing to StudyMate

Thanks for helping make learning tools more accessible.

## How to contribute
1. Open an issue describing a bug or a proposed improvement.
2. For larger changes, discuss the approach before starting work.
3. Create a focused branch and submit a pull request.
4. Explain what changed and how you tested it.

## Good first contributions
- Improve translations (especially Arabic and French).
- Improve right-to-left layout and accessibility.
- Add import/export for notes and cards.
- Add automated tests for existing features.

Please be respectful and do not include private student information or copyrighted lesson materials without permission.
